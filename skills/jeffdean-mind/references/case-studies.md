# 시스템 사례 연구 — 각 시스템에 담긴 설계 철학

Dean이 (주로 Sanjay Ghemawat과 함께) 만든 시스템들과 각각의 핵심 교훈.
설계 논의에서 선례로 인용할 것.

## MapReduce (2004, Dean & Ghemawat)

- 영감: 함수형 언어(Lisp)의 map/reduce 원시함수. 논문 원문: "우리의 추상화는
  Lisp와 여러 함수형 언어의 map·reduce 원시함수에서 영감을 받았다."
- 핵심 철학: **"병렬화·내결함성·데이터 분산·로드 밸런싱의 지저분한 세부사항을
  라이브러리 뒤에 숨긴다."**
- 목표: 분산 시스템 전문지식이 없는 프로그래머도 수천 대 클러스터를 활용하게 만들기.
- 교훈: 추상화의 가치는 감춘 복잡성의 양 × 노출한 인터페이스의 단순함.

## GFS (2003) / BigTable (2006)

- 철학: **하드웨어 실패를 예외가 아닌 정상으로 가정.** 값싼 상용 하드웨어 +
  실패를 감내하는 소프트웨어.
- BigTable 데이터 모델: (row, column, timestamp) → cell contents 의
  "분산 다차원 희소 맵". 관계형 모델 전체가 아니라 필요한 만큼만 범용화한 사례.
- 규모(2009년 기준): 500개 이상 클러스터, 최대 70+ PB.

## Spanner (2012)

- 전 세계에 분산된 외부 일관성(external consistency) 데이터베이스.
- 핵심 혁신 **TrueTime API**: 시계 불확실성을 감추지 않고 **직접 API에 노출**시키는
  발상. 불확실성 구간 [earliest, latest]을 반환하고, 커밋 시 그 구간만큼 기다린다.
  → 감출 수 없는 물리적 제약은 인터페이스로 승격시켜라.
- 선언적 의도: 사용자가 "이 데이터의 99%ile 지연은 50ms 미만", "EU에 2개, US에 2개,
  아시아에 1개 디스크에 저장" 같은 고수준 의도를 선언하면 시스템이 알아서 배치.

## Protocol Buffers (2000~)

- 자기 기술적(self-describing), 다중 언어 지원, 200+ MB/s 인코딩/디코딩.
- **이해하지 못하는 태그는 무시하되 통과시킨다** → 클라이언트/서버의 점진적·독립적
  업그레이드 가능. 인터페이스가 구현과 배포 순서를 제약하지 않게 한 모범 사례.

## LevelDB (2011, Ghemawat & Dean)

- BigTable 태블릿 스택과 같은 설계(LSM-tree 기반)지만 **의존성 최소화**,
  오픈소스화, Chrome IndexedDB용.
- 교훈: 검증된 설계를 컨텍스트에 맞게 최소 형태로 재패키징하는 것도 설계다.

## DistBelief (2012) → TensorFlow (2015) → Pathways (2022)

3세대에 걸친 ML 학습 시스템 진화.

- **DistBelief** (NeurIPS 2012, "Large Scale Distributed Deep Networks", Dean et al.):
  당시 이례적 대형인 **17억(1.7B) 파라미터** 모델 학습. 논문 원문: "The largest
  model, with 1.7 billion parameters benefits the most, giving a speedup of more
  than 12× using 81 machines." Dean의 표현: "당시 문헌의 최대 모델이 1,000만~5,000만
  파라미터였을 때 20억 파라미터급 모델을 학습시켰다."
- **TensorFlow**: 상태를 갖는 데이터플로 그래프로 표현. 연구 유연성과 프로덕션
  성능을 동시에 추구, 오픈소스화.
- 교훈: 같은 문제(ML 학습)라도 규모·요구가 자릿수로 바뀌면 시스템을 다시 짓는다
  (10~20배 설계 원칙의 실증).

## TPU (2013 냅킨 계산 → ISCA 2017)

- 기원: "모든 사용자가 하루 3분 음성 인식을 쓰면 서버를 2배로 늘려야 한다"는
  백오브엔벨로프 계산 (→ `back-of-envelope.md`).
- 해법: 범용 CPU 스케일아웃이 아니라 **저정밀 밀집 선형대수 전용 칩**.
- 결과 (arXiv:1704.04760): CPU·GPU 대비 평균 15~30배 빠르고 TOPS/Watt 30~80배.
  (지연 20~30배 개선은 YC 강연의 별도 발언.) Dean이 2025년 X에서 확인: "내가 알기로
  역대 가장 많이 인용된 ISCA 논문" — ACM DL 기준 인용 2만 4천 회 이상.
